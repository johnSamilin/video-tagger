# Video Tagger — рестайлинг

Статус: **в приложение внедрены 2 темы** — `gnome` и `teenage-engineering`
(переключатель в шапке приложения, сохраняется в localStorage).
Остальные варианты доступны в превью `preview.html`.

## Как посмотреть

Открой `themes/preview.html` в браузере (или Electron). Сверху — переключатель
из 5 тем; макет приложения меняется на лету.

```
themes/
  base.css                 # раскладка + дизайн-токены (CSS-переменные)
  gnome.css                # вариант 1
  teenage-engineering.css  # вариант 2
  neo-brutalism.css        # вариант 3
  glass.css                # вариант 4
  nord.css                 # вариант 5
  preview.html             # интерактивное превью (переключатель тем)
```

## Варианты

| # | Тема | Характер |
|---|------|----------|
| 1 | **GNOME (Adwaita)** | Native Linux. Светлый, спокойный, палитра libadwaita, синий `#3584e4`, скругления 8–12px, headerbar. |
| 2 | **Teenage Engineering** | Крем + тёплый серый + чёрный + фирменный оранжевый `#FF4D00` и жёлтый. Плоский, графичный, углы 2px, жирные заглавные надписи, моно-метаданные, «аппаратный» стиль. |
| 3 | **Neo-brutalism** | Кремовый фон, жирные чёрные рамки 2px, жёсткие смещённые тени, нулевой радиус, кричащие акценты (розовый/жёлтый/синий/зелёный). |
| 4 | **Glass (macOS/aurora)** | Замороженное стекло (`backdrop-filter`), пастельный градиентный фон, скругления 14–20px, мягкие тени, iOS-синий. |
| 5 | **Nord** | Тёмный, спокойный, терминальный. Палитра Nord, ледяной циан `#88C0D0`, углы 4px, моно-шрифты. |

## Как устроено

Вся визуальная «шкурка» вынесена в CSS-переменные (`--bg`, `--accent`,
`--radius`, `--shadow`, `--font-*` и т.д.), определённые в `base.css` как
значения по умолчанию. Каждый вариант — это файл, который переопределяет эти
переменные под селектором `html[data-theme="…"]` и добавляет немного
«характерных» правил (тени кнопок, формы элементов, регистр надписей).

После выбора темы её можно внедрить в приложение одним из способов:

1. **Быстрый**: перенести переменные выбранной темы в `:root` файла
   `src/index.css` (и при необходимости — характерные правила).
2. **Полноценный**: подключить файлы тем и добавить переключатель
   (`data-theme` на `<html>`) в шапку приложения.
